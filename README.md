# Proyecto Final - Primer Semestre IA Aplicada ICESI

Este es el proyecto final del primer semestre de Inteligencia Artificial Aplicada de la Universidad ICESI.

## Estructura del Proyecto

```
proyecto_realpe_miaa_2025/
├── data/
│   ├── raw/          # Datos originales sin procesar
│   └── processed/    # Datos procesados y listos para el modelo
├── models/           # Modelos entrenados guardados
├── notebooks/        # Jupyter notebooks para análisis y exploración
├── src/             # Código fuente del proyecto
├── results/         # Resultados, gráficos y reportes
├── docs/            # Documentación adicional
├── requirements.txt # Dependencias de Python
└── README.md       # Este archivo
```

## Instalación

1. Clona este repositorio
2. Instala las dependencias:
```bash
pip install -r requirements.txt
```

## Uso

1. **Análisis Exploratorio**: Ejecuta los notebooks en la carpeta `notebooks/`
2. **Procesamiento de Datos**: Utiliza los scripts en `src/data_preprocessing.py`
3. **Entrenamiento de Modelo**: Ejecuta `src/train_model.py`
4. **Evaluación**: Revisa los resultados en `results/`

## Notebooks Disponibles

- `01_exploratory_data_analysis.ipynb`: Análisis exploratorio de datos
- `02_data_preprocessing.ipynb`: Preprocesamiento y limpieza de datos
- `03_model_training.ipynb`: Entrenamiento y evaluación de modelos

## Componentes del Proyecto

### 1. Análisis de Datos
- Exploración y visualización de datos
- Identificación de patrones y correlaciones
- Detección de outliers y valores faltantes

### 2. Preprocesamiento
- Limpieza de datos
- Transformación de variables
- Ingeniería de características

### 3. Modelado
- Implementación de algoritmos de machine learning
- Evaluación de métricas de rendimiento
- Optimización de hiperparámetros

### 4. Resultados
- Visualizaciones y reportes
- Interpretación de resultados
- Conclusiones y recomendaciones

## Tecnologías Utilizadas

- Python 3.8+
- NumPy, Pandas para manipulación de datos
- Scikit-learn para machine learning
- Matplotlib, Seaborn, Plotly para visualización
- Jupyter Notebooks para análisis interactivo
